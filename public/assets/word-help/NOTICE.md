# Dictionary data

This directory contains modified FreeDict data, licensed under GPL-2.0-or-later,
separate from the application code. The Spanish-English and Spanish-Portuguese
dictionaries have been reversed. Portuguese fallback equivalents were joined
through Portuguese-English and are marked `indirect`; they are suggestions,
not verified contextual translations. Some entries are historical or incomplete.

Original dictionaries: https://github.com/freedict/fd-dictionaries
Spanish-Portuguese copyright (C) 2014–2017 Fred Maranhão.
Other attribution and full copyright notices are preserved in the source TEI headers.

Complete corresponding TEI sources, original license notices, pinned commit and
SHA-256 hashes: `external-data/freedict/` in this application's public repository.
Conversion script: `scripts/build-word-dictionaries.py`.
A copy of the GPL is included in `COPYING`.
