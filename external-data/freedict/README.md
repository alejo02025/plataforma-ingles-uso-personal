# FreeDict data sources

Original TEI sources and copyright/license notices are retained unmodified.
`SOURCES.json` records the upstream revision and checksums. Regenerate derived
JSON with `python scripts/build-word-dictionaries.py`.

Derived files are separately distributed as GPL-2.0-or-later data in
`public/assets/word-help/`; inversion and indirect matches are described there.
Handwritten application examples and explanations are separate from this data.
