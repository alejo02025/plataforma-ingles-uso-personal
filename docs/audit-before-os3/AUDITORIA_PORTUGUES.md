# Português OS: revisión pedagógica y de uso

## Hechos verificados

131 clases, 214 comprobaciones; distribución A1 31, A2 46, B1 14, B2 14, C1 13, C2 13. Diagnóstico de 24 ítems. Se preserva A1 como inicio de Jazmín y cualquier avance existente.

Muestras inspeccionadas: `pt-meet`, `pt-routine`, `pt-stories`, `pt-opinions`, `pt-nuance`, `pt-paraphrase`. Sus modelos de _ser_, _você_, _gostar de_, perfeito/imperfeito, _embora_ y alcance de _nem todos_ son correctos. La muestra A2 aclara que _tu estudas_ corresponde a conjugación tradicional; la enseñanza principal usa _você_ con tercera persona. Las muestras C1/C2 no bastan para una clasificación avanzada.

## Política lingüística

La navegación y las tareas usan portugués brasileño. La explicación pedagógica admite apoyo explícito en español; el modelo corregido está en portugués. Un texto español dentro de un bloque marcado de apoyo no se trata como un error de localización. Los nombres English OS y Português OS se mantienen como identidades de producto.

La reconstrucción corrigió una interacción real entre el traductor de build y las nuevas áreas: sus identificadores ahora son estables y sus pestañas se muestran en portugués. No se añadió una traducción automática del inglés como supuesto curso original de portugués; se conservan el catálogo y las situaciones propios del idioma.

## Integración implementada

Hoy propone una clase o práctica vinculada al bloque, con tareas complementarias reales. Clases muestra cuatro lecciones y requisitos concretos. La guía siempre libre incluye formación de frases, tiempos, verbos, consulta y notas por nivel. Repaso reúne palabras, errores, práctica contextual y escucha/grabación. Biblioteca agrupa los PDFs, las lecturas y las noticias.

El guardado local es automático; Jazmín no necesita GitHub para comenzar o conservar práctica en ese navegador. La sincronización entre dispositivos continúa opcional dentro de Ajustes. No se confunden datos del idioma con la actualización compartida de la aplicación.

## Aspectos aún no acreditados

No se ha realizado una validación semántica manual de las 131 clases ni una evaluación externa del currículo. Contracciones, concordancia, nasales, sonidos, falsos cognados e interferencias requieren observación y transferencia; dos respuestas cerradas no demuestran dominio. El audio grabado no recibe una nota inventada de pronunciación. La voz sintética sirve como apoyo y comprensión limitada a sus preguntas.
